# Portfolio Site

A React portfolio app connected to a custom Express and MongoDB backend API.

## Live Site Links

- **Front-End Site:** https://devportfoliovoran.netlify.app
- **Backend API:** https://portfolio-admin-dashboard-9gz5.onrender.com

## 🛠️ Features

- **Backend API Integration:** Reads projects and skills data dynamically from MongoDB.
- **Search & Filter:** Search projects by title and filter by technology.
- **Contact Form:** Working EmailJS message integration.
- **Responsive Design:** Built with Bootstrap.

## Run Locally

1. Clone the repo and install dependencies:
   ```bash
   git clone https://github.com/voranzovv/DevPortfolio
   cd DevPortfolio
   npm install
   npm run dev
   ```
